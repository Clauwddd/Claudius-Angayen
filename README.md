# Claudius Angayen | Portfolio

Personal portfolio of Claudius Braylle O. Angayen, a first-year BS IT / CS student at CITCS.

## Pages
- `index.html` : home page
- `about.html` : short bio and personal info
- `achievements.html` : certificates grouped by category, click one to enlarge

Each page fits one screen, so nothing scrolls.

## Folders
- `css/style.css` : all styling, including the black and light themes
- `js/main.js` : theme toggle, typing effect, phone switcher and footer year
- `images/` : `photo.jpg` and `logo.svg`
- `images/achievements/` : certificate photos

## Editing
- Text: edit `index.html` or `about.html`.
- Colors: change the values at the top of `css/style.css`.
- Typing phrases: change the `phrases` list in `js/main.js`.
- Certificates: copy a new JPG into `images/achievements/`, then copy one `<li>` card in `achievements.html` inside the right category and change its image path, title and subtitle.
- Photo: replace `images/photo.jpg` with a new file of the same name.

## Hosting
Turn on GitHub Pages in Settings, Pages, then choose the `main` branch and `/ (root)`.
